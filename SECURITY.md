# Security Policy

This is an educational vulnerability research repository.

- Test only systems you own or are explicitly authorized to assess.
- Keep vulnerable containers isolated and disposable.
- Do not publish vulnerable services to a LAN or the internet.
- Do not use real credentials or production data.
- Do not add persistence, destructive payloads, host access or container escape attempts.
- Use bounded, harmless proof markers.
- A crash does not prove remote code execution.
- Record exact versions, configuration and patch comparisons.

Report defects in this lab through GitHub Issues.
